# AI-Assisted Development — v2.0.0

The v2.0.0 diagnostic, reverse-engineering, implementation, integration, and documentation workflow was assisted by **OpenAI ChatGPT (GPT-5.6 Sol)**.

The model assisted with interpreting Linux/Fedora/KDE logs, HID/ACPI behavior, designing the userspace daemon and control architecture, integrating the selected animation engines, and documenting the release.

Physical hardware behavior was validated by the project maintainer on the actual ASUS ExpertBook B9400CBA/B9450CBA. Observed colors, HID responses, AC/battery transitions, notification behavior, performance-profile behavior, Effect 14 reset behavior, and persistence results were not simulated by the model.
